# D2R PCVR Plus library artwork

This directory contains the four artwork variants approved by the project owner:
Flat Screen, SteamVR, WiVRn and Virtual Desktop. Each variant supplies a PNG icon,
a vertical cover, a horizontal cover, a hero background and a transparent logo.
The source hashes and final asset hashes are recorded in manifest.json.

The original Diablo II: Resurrected promotional illustrations and logos were
provided by the project owner in D2R-Plus-media.zip. They remain copyright Blizzard
Entertainment and are not relicensed under the project's MIT software license.
PCVR Plus identification badges were composited onto those supplied images.
These fan-project visuals do not imply endorsement by Blizzard Entertainment,
Valve, WiVRn or Virtual Desktop. No game binaries, archives or extracted gameplay
assets are included here.

The installers verify SHA-256 hashes before applying artwork. Steam grid files
are keyed by each shortcut's unsigned 32-bit app ID. Existing Windows shortcuts
are renamed in place while retaining their IDs, play history and tags. The
original game's artwork is not replaced.
